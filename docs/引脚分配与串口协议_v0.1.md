# LDC1614 微缝隙测量装置 — 验证板引脚分配与串口协议

版本 v0.1（2026-10-09）
适用对象：Board1 功能验证/调试板（STM32F103C8T6 + LDC1614RGHR + 板载双 PCB 线圈）

---

## 1. 硬件状态

- 供电：Micro-USB 5V -> ME6211C33 LDO -> 3.3V。USB 数据线暂未连接，仅取电。
- 无 OLED。人机界面只有复位按键 SW1 和电源指示灯 LED1。
- LDC1614 走 I2C；40MHz 有源晶振供 CLKIN；8MHz 无源晶振供 STM32。
- 温度补偿暂时用 STM32 内部温度通道（ADC1_IN16），无外部温度传感器。
- CH340 + USART1 上位机串口：待加，本版未画。

## 3. 串口协议草案（上位机看距离用）

物理层：USART1，PA9/PA10，3.3V TTL，接 CH340；8N1，默认 115200。

### 3.1 周期上报（MCU 主动，默认 100ms 一条）

```
$D,<间隙mm>,<温度C>,<状态>\r\n
```

例：`$D,0.523,28.5,0`

状态位：0 = 正常，1 = 提醒，2 = 报警，3 = 故障。

### 3.2 调试帧（带原始数据，标定/排查用）

```
$R,<f0>,<f1>,<比值>,<间隙mm>,<温度C>,<状态>\r\n
```

例：`$R,3953210,3948021,1.00131,0.523,28.5,0`

f0 / f1 = LDC1614 双通道 28 位原始转换值；比值 = f0 / f1。

### 3.3 上位机下发的命令（可选）

| 命令 | 功能 | 返回 |
| --- | --- | --- |
| `READ` | 立刻返回一帧 `$D` | `$D,...` |
| `RAW` | 立刻返回一帧 `$R` | `$R,...` |
| `RATE,100` | 设置上报周期 ms，0 = 停止主动上报 | `OK` / `ERR,1` |
| `STX,0.800` | 设置报警阈值 | `OK` |
| `ST2,0.500` | 设置提醒阈值 | `OK` |
| `CAL,3,0.500` | 录入第 3 个标定点 = 0.500mm | `OK` |
| `CALS` | 保存标定表到 Flash | `OK` |
| `INFO` | 返回版本、参数、状态 | `INFO,v1.0,...` |

### 3.4 示例

```
$D,0.783,28.5,0
$D,0.789,28.6,0
$D,0.802,28.6,2
```

上位机按 `$D` 分割，第 2 个字段就是距离（mm），第 4 个字段决定显示颜色即可。

## 4. 待确认事项

1. OSC1 的 pin1（Tri-state）接 GND 是否仍输出 40MHz。建议加三选一焊盘（GND / 悬空 / 3V3），或打样后直接用示波器量 CLKIN。
2. 两颗板载线圈哪颗是测量（MEAS）、哪颗是参考（REF），丝印对比度太低看不清。
3. CH340 是板载芯片还是外接 USB-TTL 模块。
4. 串口默认参数：波特率 115200、上报周期 100ms、上位机是否只显示距离、原始帧 `$R` 是否默认开启。
